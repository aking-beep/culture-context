# Product roadmap

## Phase 0 — proof

Five destinations, mobile web, sourced brief, no account required.

Success signal: users open source cards, save/share a brief, or return because something changed.

## Phase 1 — trustworthy utility

- direct government/regulator adapters
- source snapshots
- change history
- saved trips
- email/push change notifications
- home-v-destination comparison

## Phase 2 — live travel mode

- local city/region rules where reliable sources exist
- disruptions, weather and holidays
- offline brief
- optional coarse location, explicitly permissioned

## Phase 3 — distribution

- B2B API for travel companies, universities, relocation platforms, insurers and corporate mobility
- embeddable pre-departure brief
- compliance/update webhook

The B2B data/API layer may eventually be more defensible than the consumer app.
