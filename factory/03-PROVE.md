# Step 3 — Prove

Capture the before state before editing and the after state using the same route/command/data/viewport. Prefer measured numbers, then screenshots/recordings/terminal output. Tests support evidence but do not replace user-visible or operational proof.

```bash
bash scripts/factory-prove.sh <slug> before
bash scripts/factory-prove.sh <slug> after
```

Complete `evidence/<slug>/EVIDENCE.md`, including what the evidence does **not** prove.
