# Governance

Culture Context treats source publication, authentication/authorization, user location/profile data, notifications, subscriptions, and production app-store releases as governed work.

Required validation for affected features: unit tests, integration tests, grounding/safety eval, dependency scan, secret scan, cost budget where AI/cloud calls are added, and staging/device smoke tests.

Human approval is required for production release, auth-model change, privilege expansion, source-policy change, and any change that publishes a new legal requirement to users.
